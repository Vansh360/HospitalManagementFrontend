# Hospital Management System Frontend

A modern JavaFX-based frontend for Hospital Management System.

## 🚀 Technologies Used

- Java
- JavaFX
- CSS
- REST API Integration

---

# Features

✅ Add Patient  
✅ View Patient Records  
✅ Interactive Dashboard  
✅ Charts & Analytics  
✅ Responsive Sidebar  
✅ Backend API Connectivity  

---

# Backend API

Connected with Spring Boot backend deployed on Render.

Example API:

https://hospitalmanagementbackend-959x.onrender.com/patients
