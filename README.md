# Hospital Management System Frontend

A modern JavaFX-based frontend for Hospital Management System.

## 🚀 Technologies Used

- Java
- JavaFX
- CSS
- REST API Integration

✅ Add Patient  
✅ View Patient Records  
✅ Interactive Dashboard  
✅ Charts & Analytics  
✅ Responsive Sidebar  
✅ Backend API Connectivity
